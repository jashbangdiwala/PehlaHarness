Phase 0 Done

The bot you already have

Phase 0 is finished. This page records what it is, how to run it and how to set it up again on a fresh machine.

What v0 is

A Telegram bot on your Mac that can hold a one-line conversation. It has no memory and no tools yet. What it does have are the four foundations everything else is built on:

  • It only answers you. A message from any other Telegram account is logged and ignored. This is an allowlist.
  • It reaches the model through one function. Anything that looks like a card number or an API key is replaced before the text leaves your Mac.
  • It logs every step to a database file on your Mac, and each row points to the row that caused it.
  • Its secrets live in the macOS Keychain, never in the code.

How it works follows one message through all of this.

Run it

Terminal, in the repo folder
source .venv/bin/activate
caffeinate -s python main.py

source .venv/bin/activate switches this Terminal window to the project's own Python. You need it in every new window. caffeinate -s keeps the Mac awake while the bot runs on mains power. Ctrl-C stops the bot.

After Phase 1 step 1 the second line becomes caffeinate -s python -m channels.telegram.

Read the log

Terminal, second tab
sqlite3 ea.db "select id, kind, substr(payload,1,80) from events order by id desc limit 8"

Each message you send produces three rows: message, model_call (with the token counts and the seconds it took) and reply. A message from a stranger produces one dropped row.

You will also see error rows that say ReadTimeout or Connection reset. Those are the network dropping while the bot waits for Telegram, usually when the Mac sleeps or changes Wi-Fi. The bot retries by itself.

Run the tests

Terminal
pytest -q

It should say 2 passed. To see why the tests exist, comment out one line of PATTERNS in egress.py, run pytest again and watch it fail. Then undo the change.

Set it up on a new machine

Everything below is needed once per machine. None of it is stored in the repo, because it is all secret or personal.

1CodeClone the repo, make the Python environment.
2BotCreate it with @BotFather.
3KeyAn OpenRouter key with a credit limit.
4KeychainStore both secrets.
5LockSave your Telegram ID.

1. Get the code and its Python environment

Terminal
python3 --version
git clone https://github.com/jashbangdiwala/PehlaHarness.git
cd PehlaHarness
python3 -m venv .venv
source .venv/bin/activate
pip install httpx keyring pytest

You need Python 3.10 or newer. Keep the folder out of iCloud and Dropbox, because the database will live in it.

2. Create the Telegram bot

In Telegram, message @BotFather, send /newbot and choose a name. It gives you a token. Treat the token like a password.

3. Create an OpenRouter key

At openrouter.ai, add a few dollars of credit, create an API key and set a credit limit on that key. The limit is your safety net against a runaway bill until Phase 3 builds a proper one.

4. Put both secrets in the Keychain

Terminal
python -c "import keyring,getpass; keyring.set_password('ea','telegram',getpass.getpass('telegram token: '))"
python -c "import keyring,getpass; keyring.set_password('ea','openrouter',getpass.getpass('openrouter key: '))"

Each command asks you to paste the secret, so it never lands in your shell history. macOS may ask permission the first time the bot reads them. Allow it.

5. Lock the bot to you

  1. Start the bot and send it "hi" from your own Telegram account.
  2. The Terminal prints your Telegram user ID. Stop the bot with Ctrl-C.
  3. Save the ID and start the bot again:
Terminal · use your own ID
echo 123456789 > allowed_id.txt
caffeinate -s python main.py

Send "hi" again. You should get a reply from the model.

If something fails

You seeCauseFix
A "no endpoints" errorNo provider for that model meets the no-data-collection setting.Choose another open-weight model and change MODEL in egress.py.
command not found: pythonThe environment is not active in this window.Run source .venv/bin/activate.
No reply, no errorYour ID is not in allowed_id.txt, so you are being dropped as a stranger.Look for dropped rows in the log, then redo step 5.
