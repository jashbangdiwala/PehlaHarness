The round trip

The reply takes the same path back: provider, OpenRouter, egress door, your kernel, then a sendMessage call to Telegram, which delivers it to your phone. Each hop is logged as a row in the event log.

Where it grows

New skills (food, goals, review) plug into the kernel loop. A scheduler adds a second trigger beside Telegram messages. A local model or Jev slots in behind the same decision seam. A VPS would replace only the green box. Nothing else changes.
