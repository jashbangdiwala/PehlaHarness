  1. One anchor first. Each block names a single thing to watch or read before you build. Do not pile up five videos.
  2. Search terms are for when you are stuck, not a watch list. Paste them into YouTube as written.
  3. You are done learning the phase when you can answer the "got it when" questions out loud, without notes. Those are the interview questions.
  4. X is for staying current, not for learning. Follow the names, skim, and save only what maps to your current phase.

Handles are from memory. If one does not resolve, search the name.

Phase 1: Loop (harness core)

  • Anchor: Anthropic's article "Building effective agents", then the AI Engineer talk on the same topic.
  • YouTube: agent loop from scratch python · tool calling explained · context engineering agents · build a coding agent from scratch · MCP explained build a server
  • X: @simonw, @swyx
  • Got it when: you can draw the loop from memory; explain workflow vs agent; say what goes into the context each turn and what gets dropped.

Phase 2: Evals

  • Anchor: Hamel Husain and Shreya Shankar on Lenny's Podcast (YouTube, search Hamel Shreya evals Lenny). Then their free 17-part email series and evals FAQ at ai.hamel.dev/eval-course. Their paid Maven course is optional.
  • YouTube: error analysis LLM Hamel · LLM as judge · align LLM judge with human labels · evaluating agents traces · golden dataset LLM evals
  • X: @HamelHusain, Shreya Shankar @sh_reya, Eugene Yan @eugeneyan
  • Got it when: you can explain why you read traces before picking metrics; how you prove a judge is trustworthy; regression eval vs capability eval; why one run is not a result.

Phase 3: Cost and tokens

  • Anchor: OpenRouter's own docs on prompt caching and provider routing (you already run on it).
  • YouTube: prompt caching explained · LLM model routing · LLM cost optimization production · context compaction agents · semantic caching LLM · LLM gateway architecture
  • X: OpenRouter @OpenRouterAI, @eugeneyan
  • Got it when: you can break one task's bill into input, output and cached tokens; explain why a cache hit needs a stable prefix; rank your three biggest cost levers with numbers from your own ledger.

Phase 4: Security

  • Anchor: Simon Willison's writing on prompt injection and the "lethal trifecta" (search Simon Willison lethal trifecta). Then the OWASP Top 10 for LLM Applications.
  • YouTube: indirect prompt injection demo · OWASP top 10 LLM explained · MCP security tool poisoning · AI red teaming agents · CaMeL prompt injection DeepMind · promptware kill chain · DEF CON AI Village
  • Read: Cloud Security Alliance research notes on agent attacks; CISA's April 2026 guidance "Careful Adoption of Agentic AI Services".
  • X: @simonw, Johann Rehberger @wunderwuzzi23, Joseph Thacker @rez0__
  • Got it when: you can explain why injection cannot simply be filtered out; point to the three legs of the trifecta inside your own EA; say which tool calls need your approval and why; walk through one attack your red-team agent landed and the fix.

Phase 5: Memory and retrieval

  • Anchor: LangChain's "RAG From Scratch" video series (short episodes, one idea each). Reuse what you learned in your agent-wikis retrieval research.
  • YouTube: hybrid search BM25 embeddings · retrieval evaluation recall precision · agent memory architecture · Karpathy LLM wiki · contextual retrieval
  • X: Jason Liu @jxnlco, Jerry Liu @jerryjliu0
  • Got it when: you can show retrieval failing separately from generation; measure recall on your own questions; explain what the nightly consolidation keeps, merges and forgets.

Phase 6: Game agent and Jev

  • Anchor: OpenRouter's Jev tutorial (openrouter.ai/docs/guides/community/jev-tutorial), then TypeSafe's docs at docs.typesafe.ai.
  • YouTube: Jev TypeSafe tutorial · System One model Jev · browser agent Playwright LLM · computer use agent explained · LLM plays 2048
  • X: TypeSafe AI's account; search Jev for what people are building
  • Got it when: you can sort every step of your game loop into "decision" or "generation"; explain calibration (a 0.9 should be right about nine times in ten); say why you pin the model version before tuning thresholds; show cost per game with and without Jev.

Phase 7: Multi-agent

  • Anchor: read two opposing pieces back to back: Anthropic's "How we built our multi-agent research system" and Cognition's "Don't Build Multi-Agents".
  • YouTube: orchestrator worker agents · multi-agent vs single agent · subagents context isolation · A2A protocol explained
  • X: Harrison Chase @hwchase17, @swyx
  • Got it when: you can argue both sides; state the token multiplier you measured; say exactly what a subagent hands back to its parent and what it must not.

Phase 8: Enterprise pack

  • Anchor: NIST AI Risk Management Framework, summary and generative AI profile.
  • YouTube: NIST AI RMF explained · ISO 42001 explained · EU AI Act for engineers · SR 11-7 model risk generative AI · AI gateway reference architecture · OpenTelemetry GenAI · agent identity OAuth
  • Where: governance people post on LinkedIn more than X. IBM Technology on YouTube is good for the vocabulary.
  • Got it when: you can map one harness control to one framework line; draw your reference architecture from memory; explain who signs off on a prompt change at a bank and what evidence they need.

Model track: Hugging Face

  • Anchor: Hugging Face's free LLM Course (search the name), then its smol-course for fine-tuning (github.com/huggingface/smol-course).
  • YouTube: LoRA explained · fine-tune BERT classifier Hugging Face · QLoRA · fine-tune embedding model sentence transformers · Unsloth fine-tuning · how to write a model card
  • X: @huggingface, Maxime Labonne @maximelabonne, Philipp Schmid @_philschmid
  • Got it when: you can say when not to fine-tune; spot overfitting on a loss curve; explain what LoRA actually trains; defend your train/test split against leakage.

Lab: LLM from scratch

  • Anchor: Raschka's free YouTube playlist that codes through the book chapter by chapter (linked from sebastianraschka.com/teaching).
  • YouTube: Karpathy Let's build GPT from scratch · Karpathy Deep Dive into LLMs · 3Blue1Brown transformers · 3Blue1Brown attention
  • X: @rasbt, @karpathy
  • Got it when: you can explain attention with your own analogy; say what the loss number means while training; explain temperature and top-k from the code you wrote.
